# VC DIT

On-set workflow platform for Digital Imaging Technicians — verified camera/sound ingest, automated scene/setup organization, sync, dailies and look management, VFX mirroring, and multi-destination delivery.

Website: [www.vc-dit.com](https://www.vc-dit.com)

## Documents

- [Development Specification v1](docs/SPEC_v1.md)

## Platform

VC DIT is a downloadable, subscription-based application.

| Concern | Service |
|---|---|
| Website, account portal, APIs | Vercel |
| Auth, database, licensing | Supabase |
| Subscriptions and billing | Stripe |
| Transactional email | Resend |

## Status

Pre-development. The UI mockup is in progress and will be added when complete.
