# Camera maker logos

Camera cards in Intake carry a small badge naming the camera that made them
(found from what is on the card: ARRIRAW is ARRI, R3D is RED, X-OCN is Sony,
and so on). Until a logo file is here, the badge shows the maker's name in
plain type.

To use a maker's own logo, put its file in this folder under the name below.
SVG is best; a PNG about 64 px tall also works. It is picked up at the next
build, with nothing else to change.

| File            | Maker                         | Where the official files are       |
|-----------------|-------------------------------|------------------------------------|
| `arri.svg`      | ARRI                          | ARRI press / media centre          |
| `red.svg`       | RED Digital Cinema            | RED press kit                      |
| `sony.svg`      | Sony                          | Sony brand / press materials       |
| `blackmagic.svg`| Blackmagic Design             | Blackmagic press / media           |
| `canon.svg`     | Canon                         | Canon press centre                 |
| `panasonic.svg` | Panasonic                     | Panasonic press / brand materials  |
| `dji.svg`       | DJI                           | DJI press / brand assets           |

Logos are their makers' trademarks. Take them from the maker's own press or
brand kit and follow its usage rules (clear space, colours, no changes). In
VC DIT they only say which camera shot a card, which is the kind of use those
kits usually allow; check each one before a public release.

Use a single-colour or dark-on-light version: the badge sits on the app's
card colour in both light and dark themes.
